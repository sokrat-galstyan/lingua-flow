# Learner customization

Example only: replace these sample preferences with the learner's own choices before saving as `docs/LEARNER_PROFILE.md`. Values describe preferences and self-report, not assessment results.

```json
{
  "targetLanguage": "English",
  "primaryLanguage": "",
  "level": "unknown",
  "goals": "Communicate in everyday situations",
  "weaknesses": "",
  "interests": "",
  "constraints": "",
  "budget": "free",
  "lessonMinutes": 60,
  "sessionsPerWeek": 3,
  "defaultLessonCount": 1,
  "includeReviews": false
}
```
