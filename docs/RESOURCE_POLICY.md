# Source and Reference Policy

## Selection hierarchy

1. Prefer an existing coherent lesson sequence that meets the objective (e.g., a verified unit in a reputable adult English course).
2. Otherwise combine existing authoritative explanations and practice, with AI generating only the connecting exercises or feedback instructions.
3. Favor a small stable resource set: British Council LearnEnglish; Cambridge English activities; Cambridge Dictionary; Cambridge Grammar in Use with answers (if purchased); Cambridge Write & Improve; VOA Learning English; BBC Learning English; USA Learns; Anki or equivalent.
4. Add specialized pronunciation or conversation applications only when a clear unmet need justifies them. State free/paid limitations and avoid unnecessary subscriptions.

## Required reference details for every assignment

- Resource name and publisher.
- Exact page / lesson / video / article title, **if verified**.
- Direct URL to the assigned item when verified; otherwise official landing page plus exact navigation instructions and `UNVERIFIED` marker.
- Type (text, listening, video, exercise, book, tool), access (free, registration, paid, unknown), estimated learner time, and any transcript/answer key requirements.
- Verification status and, when checked, date and method.

**Never invent** links, book page numbers, exercise numbers, video names, access guarantees or paywall status. Do not describe a search-engine result as confirmation that the content works for the learner. If web access is blocked, use a clearly labeled fallback assignment and flag the reference for manual verification.

## Source quality and rights

- Favor publisher, institution or creator official pages over third-party mirrors.
- For book assignments identify the book and unit only if confirmed in that edition. If unknown, describe the objective and ask the learner to find the matching unit; do not fabricate a page.
- Do not copy long copyrighted reading passages or full textbook exercises into project files. Link, summarize activities, and author original short tasks.
- Validate difficulty and approximate duration independently; if uncertain, label estimates.
- Distinguish resource availability from suitability: just because a page exists does not guarantee it matches a lesson.

## Starter resource landing pages

`curriculum/resources.md` includes official landing links to support initial research. **Those are not lesson-specific references**. Recheck when making lesson assignments.

## Repairing links

Use `workflows/05-repair-resources.md` to recheck broken or unverified references. Prefer a substitute with the same skill, grammar focus, complexity and modality; record the reason for substitution. Avoid silently replacing assigned historical material after a cycle has been completed.
