# Workflow 05 — Verify or Repair Educational References

**Trigger:** Learner reports broken links, paywalls, inaccessible videos, or an agent notes `UNVERIFIED` resource references.

1. Read `docs/RESOURCE_POLICY.md`, `curriculum/resources.md` and the affected lesson.
2. Determine the **exact skill objective**, source type and difficulty of the broken reference.
3. If internet access is available, check the original resource; distinguish removed page, transient failure, paywall, login requirement and inaccessible network.
4. Locate a reputable substitute matching **the same educational objective**. Prefer official institutions and free options. Provide title, verified direct URL, estimated duration and transcript/answer-key availability.
5. If browsing is unavailable, mark `UNVERIFIED` and provide navigation instructions or a self-contained original fallback activity. Never invent specific source details.
6. For an **active** lesson, update the resource reference transparently and add a dated correction note; for a **completed** lesson, preserve historical record and annotate the current replacement separately instead of silently rewriting what was assigned.
7. Update `curriculum/resources.md` if the replacement has lasting reuse value. Re-run relevant project checks.
